# Hi, I'm Ahmad 👋

**.NET engineer at [Spotware](https://spotware.com), building [cTrader](https://ctrader.com)** — the trading platform used by millions of traders worldwide. I work on the desktop platform, the Algo API, and the backtesting & optimization engines.

My path is a bit unusual: I spent years on the *other* side of the platform first. Since 2015 I built indicators, cBots and plugins for the cTrader community as **afhacker**, founded [AlgoDeveloper](https://www.algodeveloper.com) in 2016, and in 2020 [proposed the plugin/extension system](https://community.ctrader.com/forum/suggestions/23558/) that cTrader later shipped. Then I joined the team to build the platform itself.

## 🔭 What I work on

- **Trading platforms** — cTrader Desktop (WPF/.NET), charting, order execution UX
- **Algo trading infrastructure** — cTrader Algo API, backtesting & optimization engines, CLI tooling
- **AI developer tooling** — Roslyn-powered agents and MCP servers that make coding agents cheaper and safer on large .NET codebases
